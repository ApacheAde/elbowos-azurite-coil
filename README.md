# Azurite Coil

Full-colour Python 3 neon rotating-needle arcade for [ElbowOS](https://x.com/ElbowOS).

Spin a three-pronged azurite coil. Thread each falling magnetic ring through its copper gap.
A / D or arrow keys rotate. R restarts. Esc quits.

## Play

```
pip install -r requirements.txt
python3 azurite_coil.py --play
```

Or simply:

```
python3 azurite_coil.py
```

## Record a 9:16 reel

```
python3 azurite_coil.py --record
```

Writes `/home/workdir/artifacts/azurite_coil_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264).
